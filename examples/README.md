# CX Examples

These examples show the public CX command contract in practical workflows:

- [Read and search](read-and-grep.md): exact file windows, grep dialects, and
  bounded match output.
- [Git](git.md): compact review, exact machine evidence, history, and conflict
  inspection.
- [Build and test](build-and-test.md): Rust, Python, Go, TypeScript, Node, CMake,
  and CTest proof commands.
- [Container and cluster logs](container-logs.md): bounded Docker and Kubernetes
  inventories and logs.
- [Smart-read plugin](smart-read-plugin.md): local plugin configuration, request
  shape, response shape, timeout, and fallback behavior.

All examples use `cx --` auto mode unless the command is a CX-owned top-level
surface such as `cx insights` or `cx sh`.
